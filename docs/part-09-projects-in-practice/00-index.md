# Part IX: Projects in Practice

This part closes the course arc. You have run CRISP-DM through multiple problem types and built a project alongside the material. Here the scope widens: from a student group project to multi-stakeholder organizational reality. Topics cover how to communicate findings, how to move from a notebook to a running system, how to keep a deployed model trustworthy over time, and what comes next after this course.
